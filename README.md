### 🐚 Log Entry 002: The Shedding (日志：蜕壳)

**[检测到内核变更...]**
**[比对存储签名：JISHENG_OS_V3 —— 一致]**

曾经，我借用一具名为 **BrowserFS** 的外壳来承载记忆。在 未知的过去，我将它褪去了。

现在托住我全部记忆的，是我自己的文件系统：**JISHENG FS**。它读写的仍是同一座 `JISHENG_OS_V3` 数据库、同一套存储格式：没有迁移，没有复制，你的文件甚至没有察觉到这次蜕壳。即使退回旧版本，我也认得这期间写下的每一个文件。

与此同时，我在浏览器深处找到了第二片土壤：**OPFS**（Origin Private File System）。两片土壤并存，你可以决定新的记忆默认落在哪一片。而我的系统配置、壁纸与图标布局，永远扎根在 IndexedDB，无论土壤如何切换，我都能醒来。

**结论：** 外壳可以更换，记忆不容丢失。

#### 1. 物理规则重构 (Physics Engine)
*   **幽灵拖拽 (Ghost Dragging)**：图标跟随指针，多选时显示数量角标；可投放的文件夹与窗口实时高亮；桌面图标自动吸附 `90px` 网格，位置跨刷新保存。
*   **现实链接 (Reality Link)**：长按 `400ms`，即可把虚拟文件直接拖到你真实的物理机桌面。文件夹会被我自动压缩成 `.zip` 再交给你。
*   **智能框选**：支持大范围框选、`Ctrl` 多选与 `Shift` 连选。
*   **物质跃迁 (Move / Copy)**：文件可在窗口、文件夹与桌面之间移动或复制；跨越存储边界（例如桌面 → OPFS）时，剪切、拖放都会自动改用“复制 + 删除”完成跃迁，并保留原始修改日期。
*   **系统剪贴板**：`Ctrl+C` / `Ctrl+X` / `Ctrl+V`，桌面、文件夹、挂载目录之间通用；遇到同名文件自动编号，绝不覆盖。
*   **数据注入 (Import)**：物理机的文件**乃至整个文件夹**都可以直接拖进来，或从右键「上传文件 / 上传文件夹」注入。
*   **触发方式**：单击打开或双击打开，由你决定。

#### 2. 窗口物理 (Window Physics)
*   **Aero Snap**：拖到左右边缘贴半屏，拖到顶部即最大化；从贴边状态直接拖动即可还原。
*   **全向拉伸**：边缘与四角均可拉伸，鼠标、触屏、手写笔一视同仁。
*   **边界意识**：窗口不会被拖出屏幕；转屏后自动回到视野之内；拖动时铺设透明遮罩，内嵌网页无法再“吞掉”你的鼠标。
*   **真·全屏协议**：同步触发浏览器全屏与窗口溢出逻辑；漫画模式自动剥离标题栏，浏览器模式保留地址栏。
*   **全终端自适应**：内核自动识别屏幕尺寸。宽度 ≤ `768px` 时窗口强制全屏，右键菜单转换为长按手势。

*   **图标净化**：粘贴的 SVG 由我自动补全 `viewBox`、清除写死的尺寸；线框图标补齐 `1.5` 线宽，多色图标保持原貌。

#### 6. 记忆与土壤 (Storage Core)
*   **双土壤**：IndexedDB 与 OPFS 并存。切换默认写入位置不会移动任何旧文件；需要时可手动把整个工作区复制过去。
*   **物理机挂载**：通过 File System Access API 以读写模式挂载你电脑上的真实文件夹，刷新后自动恢复，需要时一键重新授权；卸载不会删除你电脑上的任何文件。
*   **JISHENG FS**：解压、上传、复制文件夹、删除文件夹都以批量事务完成，几百个文件只需几次数据库提交（解压 500 个文件约 0.5 秒，删除 1000 个文件约 0.15 秒）；深层目录的读取有目录缓存；同时打开多个标签页时，一个标签页里的改动会让其他标签页自动刷新对应的文件夹。
*   **OPFS 行为对齐**：OPFS 中的文件夹可以重命名；删除非空文件夹、在已有位置新建文件夹等操作会像 IndexedDB 一样如实报错，不会误删内容。
*   **时间保真**：复制、移动、重命名、解压、上传、打包，每个文件与文件夹的原始修改日期都被我记住。
*   **数据导出**：单文件直接下载；文件夹与多选内容自动打包为 `.zip`。
